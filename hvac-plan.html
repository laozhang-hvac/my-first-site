中央空调系统运行维护保养方案

机电设备及风 / 水 / 电系统 · 定期维保 · 记录体系（精简版）

适用：办公楼 / 商业综合体 / 展馆等中央空调系统
目录： 一 系统构成 二 维保分级总表 三 分设备步骤 四 厂家维保界面 五 记录体系 六 应急响应

一、适用范围与系统构成

本方案覆盖中央空调系统全部机电设备及其风、水、电关联系统，按五大块划分维护对象：

系统块主要设备
冷热源离心式 / 磁悬浮 / 螺杆式冷水机组、风冷模块化冷热水机组、水源热泵机组
水系统冷冻 / 冷却 / 供暖循环水泵、冷却塔、定压补水装置、膨胀水箱（罐）、过滤器、阀门管路
末端风机盘管、空气处理机组、组合式空调机组、新风机组
风系统送回风管、风口、防火阀、排风机
电气自控配电柜、变频器、传感器、温控器、楼宇自控
维保总原则：以运行安全为底线、以能耗经济为目标、以记录可溯为管理抓手；运行方做日常与常规保养，专业厂家做年度深度保养。

三、分设备保养详细步骤

3.1 冷水机组（离心 / 磁悬浮 / 螺杆）

  • 每班巡检记录：蒸发 / 冷凝压力与温度、油温油位（磁悬浮无油系统则查轴承状态与控制柜）、排气温度、电流电压、振动与噪音、冷媒管路结露情况；
  • 每月：控制屏自检、报警历史调阅归档、机旁仪表与就地表计比对、机房清洁；
  • 每季：冷媒管路泄漏目测（油渍处重点查）、启动柜接线目测紧固；
  • 年度（厂家执行）：冷冻油及油过滤器更换并留油样分析、导叶执行器检查、压力 / 温度传感器校验、控制参数优化、大修评估报告。
磁悬浮机组特有：无油路系统，省去换油，但控制柜除尘与变频散热风道清洁必须按季度做；轴承状态以厂家后台数据为准。

3.2 循环水泵

  • 每月：盘车灵活、润滑油位、机械密封渗漏（滴速≤规定值）、压力表读数、异响与振动；
  • 每季：轴承加脂 / 换油、联轴器对中复查、地脚螺栓紧固；备用泵每周切换运行一次，防止锈死；
  • 年度：电机绝缘摇测、轴承磨损评估更换、叶轮与泵腔检查；
  • 运行控制：轴承温度 ≤ 环境温度 +35℃ 且最高 ≤80℃；流量扬程控制在标牌范围内；
  • 冬季停用：打开泵底放水螺塞放净积水，防止冻裂。

3.3 冷却塔

  • 每月：布水均匀性、填料完整性、风扇皮带张紧与对中、减速机油位；
  • 每季：填料冲洗（结垢藻类）、水质取样化验、排污与加药、电机温升检查；
  • 年度：减速机换油、电机绝缘摇测、塔体与钢构防腐检查、风机轴承保养；
  • 水质管理：控制浓缩倍数，定期排污＋加药，配合旁滤设备，防止生物黏泥与结垢。

3.4 水泵入口过滤器（多年实战经验）

泵前过滤器的作用是拦截大颗粒、保护叶轮，不是精细过滤：采用 3-5 目（约 4.0-6.7mm 孔径）不锈钢粗滤网即可，机组换热管孔径一般 ≥3mm，粗滤完全够用。滤网过细会与黏泥、纤维形成"架桥效应"，频繁堵塞反而影响制冷。新装或改造的过滤器要核对目数与安装高度（底部盲板距地 ≥500mm，满足 GB 50243 检修空间要求），并建立清理台账（日期＋堵塞物形态＋耗时）。

3.5 风机盘管（每季 / 供冷供暖前）

  • 过滤网清洗（清水或中性清洗剂）；
  • 铝翅片用盘管清洗剂喷洗，清水漂净；
  • 叶轮除尘、电机听音；
  • 凝水盘清理消毒、冷凝水管疏通（防滴水损顶）；
  • 温控器与三速开关功能测试、电动阀动作检查。

3.6 空气处理 / 组合式空调机组

  • 每月：皮带张紧与磨损、轴承润滑、过滤段压差（超限即换滤料）；
  • 每季：表冷器翅片清洗、凝水盘与水封检查、风阀执行器动作；
  • 年度：电机轴承保养、绝缘摇测、箱体密封与保温修复。

3.7 水系统与定压补水

  • 定压补水装置每月检查：压力设定值、补水泵启停是否正常、安全阀/泄压阀动作值；
  • 膨胀水箱每季清洗；冬夏阀门季节切换时逐台核对开关状态并挂牌；
  • 系统补水量异常增大 = 有隐漏点，立即排查；首次充水必须充分排气；
  • 科学稳压 = 定压点正确 + 囊式膨胀罐（吸纳膨胀水量）+ 高区膨胀水箱（或稳压罐）三者配套，缺一不可。

3.8 电气与自控

  • 每月：配电柜巡视（仪表、指示灯、异味）、温控器抽检；
  • 每季：控制柜停电除尘、接线端子紧固、变频器散热风道清洁；
  • 年度：绝缘摇测、保护定值校验、变频器参数备份（更换设备后须重新匹配调试并留书面记录）。

五、记录体系（文字 + 电子）

5.1 文字记录四件套

记录填写时机要求
运行日志每班运行参数、异常情况、交接事项，值班员签字
维保工作单每次保养当场内容＋耗材＋工时，双方签字，各存一份
维修记录单每次故障处置后故障现象、原因、处置、更换件、验证结果
月度维保报告每月固定日当月保养完成率、故障统计、下月计划、风险提示

5.2 电子记录

  • 照片存档：每次保养现场照片按"月份＋设备位号"命名归档；
  • 电子台账：设备台账（型号 / 位号 / 投运日期）、故障台账、耗材更换台账、水质化验记录，Excel 建表；
  • 扫描归档：签字版工作单扫描存电子档；
  • 归档规则：月度装订、年度成册；合同解除或终止时全部技术档案移交甲方。

六、应急响应与常见故障速查

维保期间提供 24 小时应急服务，接通知后按合同时限（一般 2～3 小时）到场处理，直至恢复运行。
